# 🎬 Master Storyboard Prompt (our `/storyboard` method)
**Approved by King 2026-06-27.** The best-of-breed prompt that turns a script + a proven reference into a
COMPLETE, ready-to-render visual storyboard (script + visuals + flow). Built from a find-skills consensus
(Hook→Body→Payoff→CTA framework + 2026 viral-edit rules). Always produce the storyboard VISUALLY (Rule #18).

## Inputs
- **[SCRIPT]**, the VO (King reads/freestyles it).
- **[REFERENCE]**, a decoded winning video's format (via `/watch`), e.g. @hustle.faceless.
- **[CHARACTER]**, King's AI hero + style sheet (`persona_v2_c.png`) used consistently in host beats.
- **[PLATFORM]** · **[GOAL]** · **[CTA]**.

## Proven rules (bake into every board)
- **Structure:** HOOK (0, 3s) → BODY/escalation → PAYOFF (last 15, 25%) → CTA/loop (last 3, 5s). Keep the promise on-screen.
- **Hook:** one scroll-stopping line + a bold on-screen text card (the reference's hook-card style).
- **Pacing:** hard cuts every **2, 4s**; never the same shot >1 sentence; alternate shot types (hero / screen-record / b-roll / text card).
- **Retention:** open an information loop early, close it at the payoff (+~40%).
- **Captions:** burned-in, bold, word-by-word, key words highlighted, in the REFERENCE's EXACT style.
- **Hero:** the AI character appears consistently in host beats (hook + CTA + transitions).
- **Match the reference's editing** (caption style, pacing, transitions), replicate, don't reinvent ([[learning-digital-product-viral-sales-model]] TSV).

## Output (the board)
A VISUAL board, a frame mockup per shot, plus a shot table, per shot:

| # | Time | VO (script line) | On-screen text / caption (+highlight) | Visual (exact image/motion prompt + shot type) | Transition → next |

…and three closers:
- **FLOW:** one line on how the beats connect into one story (the open-loop → payoff).
- **AUDIO:** music bed + SFX + voice plan.
- **END-CARD / CTA:** the comment-to-DM + bio-link.

## House style for King's own channel (from the @hustle.faceless decode)
- **Hook headline = bold BLACK text on a WHITE rounded box.**
- **Running captions = bold WHITE, key words in YELLOW, on a semi-transparent DARK box (lower third).**
- **Hero = Character C** (`persona_v2_c.png`) in host beats; **screen-records** of the AI tool as the proof; fast hard cuts.
- CTA = "Comment HOOKS" + comment-bubble graphic (comment-to-DM).
