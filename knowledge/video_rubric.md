## 1. HOOK / RETENTION

| # | Criterion | Score | Source |
|---|-----------|-------|--------|
| H1 | Hook visible/audible within first 2-3 seconds (a question, a bold claim, or a visual provocation · not a logo intro) | PASS / FAIL | NC2 ("Any money?"), NC4 ("a ton of money"), NC3 (chalk board + question) |
| H2 | First 30 seconds has the highest cut density · at least 1 new visual every 1-3 seconds | 1-5 (3=min) | NC4 intro: 12 distinct shots in ~30s |
| H3 | At least 2 visible "retention hooks" mid-video (a question left open, a number teased, a frame cut short) | 1-5 (2=min) | NC3 retention graph frame; NC2 "if your video" cliffhanger |
| H4 | No dead air in the first 10 seconds · audio and visual move simultaneously from frame 1 | PASS / FAIL | All Curtiss videos: voiceover starts by frame 2 |
| H5 | Intro is SHORT · the real content (proof/demo) starts by second 5-8. No long logo bumper, no "hey guys welcome back" | PASS / FAIL | NH: "No code required. Let's get into it." · under 8s |
| H6 | The promise of value is stated in the first 5 seconds (what the viewer will get or learn) | PASS / FAIL | NC1: "18 editing tricks", NC2: "couple thousand dollars" on screen at 0s |

## 2. PACING

| # | Criterion | Score | Source |
|---|-----------|-------|--------|
| P1 | Average shot duration is 1-4 seconds across the first 60 seconds | 1-5 (3=min) | NC4: "cut every 1-4 seconds in the intro" (shown in timeline frame) |
| P2 | At least 1 intentional "breathing pause" · a 2-4 second held frame or slow B-roll · after the proof/midpoint | PASS / FAIL | NC3 "Editing Depends" section: static chalkboard held; NC2 sponsor pause |
| P3 | Pacing changes match section changes · noticeably faster in hook/intro, steadier in body, slower just before CTA | PASS / FAIL | NC3 retention-curve frame explicitly shows this shape |
| P4 | No two consecutive still-text-only cards lasting more than 3 seconds each | PASS / FAIL | All Curtiss: static cards always have motion overlay or character on them |
| P5 | Outro / CTA is short · no more than 5-8 seconds of pure "go follow me" content | PASS / FAIL | NC3: short CTA; NH ends on task, not promo |

## 3. CAPTIONS

| # | Criterion | Score | Source |
|---|-----------|-------|--------|
| C1 | Captions appear on-screen · never silent visual stretches over 3 seconds without text or graphics | PASS / FAIL | Every Curtiss video has continuous caption layer |
| C2 | Max 1-3 words shown at a time (pop-in subtitles), not a sentence wall | PASS / FAIL | NC1: "softcaps." single word frame; NC4 "at the same / talking / directly" · 1-3 words per pop |
| C3 | Caption font is clean, readable at mobile size · thick sans or bold weight, NOT thin script | PASS / FAIL | NC4: thick rounded caps bottom-center; NC3: clean white bold |
| C4 | Captions placed in the lower third (bottom 20-30% of frame) · never over a person's face or the key visual | PASS / FAIL | All Curtiss: bottom placement consistent |
| C5 | Key emphasis words get a scale-up, color-swap, or brief bold-flash · not every word, only 2-4 per section | 1-5 (2=min) | NC4: "talking directly", "at the same" scale-emphasis pattern |
| C6 | Captions sync to audio within ±1 frame · never lags or shows words before VO speaks them | PASS / FAIL | NH: word-level timestamp pipeline makes this exact |

## 5. TRANSITIONS

| # | Criterion | Score | Source |
|---|-----------|-------|--------|
| T1 | Big transition (zoom-punch, warp, whip-pan, ink-wipe) used ONLY at major section turns · max 2-3 per 60-second video | PASS / FAIL | NC3: "Big Transitions" written on chalkboard with red arrow; only at scene changes |
| T2 | Day-to-day cut rhythm is plain jump cuts · no dissolve, no star-wipe on routine cuts | PASS / FAIL | All Curtiss intros: hard cuts between shot changes |
| T3 | Every transition coincides with a sound effect (whoosh, impact hit, or riser) | PASS / FAIL | NC4 + NC2: sound design principle explicit in talking-head sections |
| T4 | Slow Ken Burns (2-4% scale over 2-3s) applied to any still screenshot or image · never a static dead frame | PASS / FAIL | NC4 explains this explicitly; NC2 mid: visible on website thumbnails |

## 6. SOUND / MUSIC

| # | Criterion | Score | Source |
|---|-----------|-------|--------|
| S1 | Every on-screen graphic element that appears has a corresponding sound (click, pop, whoosh, scratch, tick) | PASS / FAIL | NC4: "sound design is the single biggest thing"; NC2: every card pop has a sound |
| S2 | Background music sits at -10 to -25 dB BELOW the voiceover level · music is felt, not heard | PASS / FAIL | All Curtiss: talking head always dominant; music audible in quiet pauses only |
| S3 | Music energy changes at each major section turn · NOT the same unbroken loop for the full video | PASS / FAIL | NC4: "change music per section"; NC3: visible waveform section markers |
| S4 | A riser/swell sound builds into each section transition (half a beat before the cut) | PASS / FAIL | NC4 timeline frame: riser clip visible before section cuts |
| S5 | No copyright music · only royalty-free or the approved Rockot track | PASS / FAIL | NC4 explicitly uses "LAKEY INSPIRED · Moonrise" (non-copyright shown on screen) |
| S6 | Audio is clean · no room echo, no mic hiss audible under music | PASS / FAIL | NC4 "clean the audio first" · shown before/after in timeline frames |

## MINIMUM BAR TO SHIP

These 8 criteria must ALL pass before rendering a deliverable cut:

| # | Criterion | Why it's the floor |
|---|-----------|-------------------|
| MS1 | **H1 · Hook in 2-3s** | No hook = scroll-death before anything else can matter |
| MS2 | **H4 · No dead air in first 10s** | Silent visual opening kills faceless video |
| MS3 | **PR1 · Real site footage only** | Fake footage = trust destroyed if anyone checks |
| MS4 | **PR2 · No fabricated numbers** | King's explicit rule; one fake stat ends credibility |
| MS5 | **S1 · Sound on every moving element** | NC4: "the single biggest thing" · a silent pop-in reads as broken |
| MS6 | **S2 · Music under VO, not equal** | Music louder than voice = unwatchable |
| MS7 | **C2-1· 3 words per caption pop** | Wall-of-text caption = social media death |
| MS8 | **T1 · Big transitions only on big moments** | Overused transitions = cheap; NC3 is explicit about this |

**Scoring floor:** 6 of 8 other criteria must score 3+ (or PASS) for the video to ship. A video can be "good enough" on polish and still ship; it cannot ship with any MS failure.
