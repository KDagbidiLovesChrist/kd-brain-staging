# THE KD STORYBOARD

**The whole estate, every iota, written for a man who built all of this and remembers none of it.**

That is King's own standard for this document, set 10 September 2026: written *"as if King lost
his memory and needs deep reminder and refresher and update of his architecture and
infrastructure"*. So nothing here assumes yesterday. Every name is defined the first time it
appears, and every number is traceable to a command that was actually run.

---

## How to read this

Start at part 0 and go forward. Each part is its own file, short enough to read in one sitting,
and each ends the same way: **what is real today, what is half built, what is zero.**

That last line is the whole discipline. A document about your own work becomes a brochure the
moment it stops saying which parts do not exist.

**This is a tracker, not a document.** It fills in as the work happens. The state of every part
lives in `tools/progress_board_iotas_storyboard.py` and shows on the P&P board as stage **SB**.
It is deliberately NOT repeated here: the prose is written by hand because it has to be good, and
the state is generated because it has to be true. Two copies of a status is how a brain starts
disagreeing with itself.

## The equation, which the whole estate rests on

```
        HW   +   SW   +   CW    =    CLOUDWARE

        HW  hardware   powered, connected, able to act right now
        SW  software   the instructions and the sequences
        CW  coldware   GitHub and the hard drive. Real, and inert.

   KNOWLEDGE ──+MACHINE──> WISDOM ──+LOGIC──> LOGOS = POWER = CLOUDWARE
```

Knowledge is a library with the lights off. Wisdom is the lights on. Logos is a librarian who
reads, understands and rewrites the shelves. Power is that happening while you sleep.

**And it makes a prediction that came true before it was written down.** Oracle has a machine and
a model and almost no files it may read: two of the three. Three of its four agents refuse. The
drive is the same test from the other end, holding more knowledge than Oracle and 8.3 GB of
models, and doing nothing at all, because the machine is missing.

## The five halls, which everything is filed under

The brain is mapped as a data centre: God as the power feed, then five halls. Files already carry
names like `M-CL-THEBUKA-U01`, meaning hall M, row CL, rack THEBUKA.

```
C  Core      the brain itself, its tools, its boards, its own upkeep
W  Work      Amazon. Nothing on this laptop, by the one-way valve ruling.
M  Money     anything whose purpose is a euro
F  Faith     the-truth, and anything carrying it
T  Theosis   the life goal, faith-gated
```

**One taxonomy, five jobs.** A hall is simultaneously the workspace a window opens on, the lane
that window declares, the scope a lock will hold, the top node of the drill-down canvas, and the
label on every agent working there. That is not tidiness, it is what stops five competing naming
schemes appearing.

## The one thing to know before anything else

**Nothing in here is claimed without proof, and where something is not built it says so.**

Three examples, all true on the day this was written, all of them uncomfortable:

- The recipe book, which is meant to make solved work free forever, holds **one recipe, run zero
  times, saved nothing**. The loop is built and stopped.
- **21 of your 25 automated flows are watched by nothing.** One of them failed silently every
  night for days before anyone noticed.
- **None of your three money paths is blocked on code.** One is blocked on contact, one on a
  signature, one on a solicitor. More building moves none of them.

A document that could not say those things would not be worth reading.
