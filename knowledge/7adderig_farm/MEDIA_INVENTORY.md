## What the EMPTY WALKTHROUGH shows · EXISTING CONDITIONS (design around these)

The house is a **modern new-build townhouse in a Dublin estate**, handed over at builder-finish, **not a bare shell**. Several big-ticket items are ALREADY installed, which changes the fit-out scope and budget:

1. **Kitchen is already fitted**, white handleless gloss units, wall + base cabinets, extractor hood. Design the kitchen/dining *around the existing white units* (worktop styling, splashback, dining furniture, bar stools, decor) rather than a full rip-out.
2. **Wet rooms are already tiled + plumbed**, the WC, main bathroom (bath + toilet) and ensuite (basin) have tiled floors and sanitaryware in. Scope = finishing touches (mirrors, lighting, storage, towel/decor, paint), not a re-fit.
3. **Stairs are bare untreated pine**, spindles/balustrade in white, treads raw timber. Needs a decision: paint + runner, stain, or carpet.
4. **Ground floor = bare grey screed** throughout (hall, living, kitchen/dining), awaiting flooring. This is where the per-room flooring choice (wood / wood-effect LVT) actually gets laid.
5. **Upstairs bedrooms are already carpeted** in a neutral beige builder carpet, and have **sloped / vaulted ceilings with Velux roof windows + dormer windows** (top-floor, under-the-roof rooms). **Important for bedroom design:** these are attic-style rooms, plan wardrobes, bed walls and lighting around the slopes and low eaves; tall furniture only on the full-height walls.
6. **Walls = builder white** throughout, consistent with the standing rule to go one shade warmer/darker (warm greige) than builder white.
7. Windows are large and bright; estate/other houses visible out the front and rear windows (so window dressing should balance light + privacy).
