## Chapter 4 · The WAT Framework

WAT = Workflow → Agent → Tool → Skill → Money

Think of it like a restaurant kitchen:

```
WORKFLOW = The Recipe Book
  A written set of instructions. Stored as a .md file.
  "First do this, then this, then this."

      ↓

AGENT = The Head Chef (Claude)
  Reads the recipe. Thinks. Decides which tools to use.
  Doesn't work with bare hands, uses kitchen equipment.

      ↓

TOOL = The Kitchen Equipment
  The things that DO the actual work.
  Web scrapers. Browsers. Email senders. APIs.

      ↓

SKILL = The Order Ticket
  You say ONE word (/scrape) and the entire kitchen fires up.
  Recipe → Chef → Tools → Done.

      ↓

MONEY
```

Every automation follows this chain. Every idea can become a skill.
