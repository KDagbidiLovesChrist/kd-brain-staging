## 8. EXACT RECREATE RECIPE
Here's a step-by-step plan to rebuild this style for a mobile app promo:

1.  **Project Setup:**
    *   **Composition:** 1920x1080, 24-30fps.
    *   **Background:** Solid layer with a light gray color (e.g., `#E8E8E8`) for initial scenes, and a dark gray/black (e.g., `#1A1A1A`) for others. Apply a subtle `Noise` (e.g., 5-8%) effect to the background layer for texture.
    *   **Text Color:** Dark gray (e.g., `#333333`) on light backgrounds, off-white (e.g., `#EAEAEA`) on dark backgrounds.
    *   **Line/Dot Color:** Same as text color.

2.  **Typography Styling:**
    *   Choose a clean geometric sans-serif font (e.g., Avenir Next LT Pro, Lato, Montserrat).
    *   Use `Medium` or `Light` weight.
    *   Set `Tracking` to -10 to -20 for a tight, modern feel.
    *   Font size: 80-120px for primary words, smaller for phrases.

3.  **Core Text Animation (Kinetic Typography):**
    *   **Entry:** `Opacity` from 0-100% (0.5-0.7s, `Ease In/Out`). Simultaneously, `Scale` from 95% to 100% (or `Position` shift 5-10px up).
    *   **Exit:** Reverse of entry animation, or `Luma/Alpha Matte` reveal.
    *   Use `Text Animators` in After Effects for per-character or per-word animation for nuanced effects.

4.  **Line Animation (Geometric Shapes):**
    *   Create `Shape Layers` for squares, octagons, etc. (e.g., using `Polystar Tool` for octagons, then converting to Bezier path for modifications).
    *   Apply `Trim Paths` animator to these shapes. Animate `Start` or `End` (or both with `Offset`) from 0-100% over 0.7-1.2 seconds.
    *   Set `Stroke Width` to 2-3 pixels.
    *   Add small circle `Shape Layers` (dots) at line endpoints. Animate their `Scale` from 0-100% over 0.2 seconds (`Ease In/Out`) to appear with the lines.
    *   For complex patterns, layer multiple shape layers and animate `Trim Paths` sequentially or simultaneously.
    *   Use subtle `Rotation` (e.g., 5-10 degrees over 3-5 seconds) for background geometric elements.

5.  **Dot/Particle Animation (Organic Clusters & Bursts):**
    *   **Small Dots:** Create small `Shape Layer` circles (dots, 4-8px diameter). Use `Repeater` or distribute manually. Animate `Opacity` and `Scale` from 0-100% (0.2-0.4s, `Ease In/Out`).
    *   **Organic Clusters:** Position multiple dot shapes (varying sizes, 4-20px diameter) manually or using `Particle Systems` (like CC Particle World/Ball Action) to form a loose grouping. Animate the `Position` and `Scale` of the entire group.
    *   **Dot-to-Line Burst:**
        *   Create a central dot.
        *   Create numerous smaller dots scattered around it.
        *   For each scattered dot, create a `Shape Layer` line from the central dot to the scattered dot.
        *   Apply `Trim Paths` to each line. Animate `Start` from 100% to 0% (or `End` from 0% to 100%) over 0.3-0.6s. Stagger these animations slightly for a burst effect.
        *   Simultaneously, animate the `Scale` of the scattered dots from 0% to 100%.
    *   **Particle Field:** Use `CC Particle World` or `Trapcode Particular` (for AE) for floating particles. Adjust `Producer Radius`, `Velocity`, `Longevity`, `Gravity` to create a slow, drifting effect. Use white particles on dark backgrounds, black on light. Blur some particles (e.g., `Fast Box Blur`) for depth of field.

6.  **Shape Transitions (Circle Reveals):**
    *   Create a `Shape Layer` circle. Animate its `Scale` from 0-100% (or 100-0%) over 0.8-1.5 seconds with `Ease In/Out`.
    *   Use this circle as an `Alpha Matte` or `Luma Matte` for background layers or text elements to reveal them.
    *   Apply `Noise` to the revealing circle for consistency (e.g., 5-8%).

7.  **Easing & Timing:**
    *   Almost all keyframes should use `Easy Ease` or `Ease In/Out` in the `Graph Editor` to create smooth, non-linear acceleration/deceleration.
    *   Experiment with slight overshoots (e.g., 105% scale then back to 100%) for more subtle bounce.
    *   Scene durations: 4-8 seconds for complex animated scenes, 2-3 seconds for simple text reveals.

8.  **Sound Design:**
    *   **Music:** Find a minimal, piano-driven, emotionally resonant track (BPM 80-100). Cut motion to musical cues.
    *   **SFX:** Use subtle, clean sound effects.
        *   *Clicks/Pops:* for dots appearing/lines starting.
        *   *Soft Whooshes:* for larger movements, line draws, or scene transitions.
        *   *Shimmer/Chime:* for moments of emphasis or concepts like "delight."
        *   *Subtle Digital Tones:* for UI elements if showcasing an app.

9.  **App Showcase Integration (Adaptation):**
    *   For app screens, treat them as rectangular `Shape Layers` or simple image imports.
    *   Animate UI elements (buttons, text fields, icons) using the kinetic typography and dot/line animation techniques. For example, a "send" button could appear via a small line drawing a box around it, then the word "send" fades in.
    *   Connect user flows with `Trim Paths` lines, maybe with small dots indicating touch points.
    *   Avoid complex 3D device renders; stick to flat, clean, 2D representations.
