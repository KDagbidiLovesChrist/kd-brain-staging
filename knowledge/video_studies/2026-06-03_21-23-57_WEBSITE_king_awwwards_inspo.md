    *   Subtle shifts in the plasma's glow and intensity.
    *   The central icon subtly morphing or animating.

*   **0:27 - 0:33 (Standard Vertical Scroll for New Site):** After the scroll-scrub animation concludes its sequence, the page would transition to standard vertical scrolling to reveal subsequent content sections (e.g., feature details, related elements).

## 9. RECREATE RECIPE (for the 'AI clip scrubbed on scroll' workflow)

**Goal:** Create a stunning, scroll-scrubbed hero section on a new client website, visually replicating the "plasma ball" effect using an AI-generated clip and a smooth scroll library.

**Concrete Plan:**

1.  **AI-Generated Cinematic Hero Clip Creation:**
    *   **Concept:** Generate a high-quality, continuous video animation of a "plasma ball."
    *   **Prompt (Example):** "A futuristic, vibrant pink and electric blue plasma sphere against a dark, deep violet void. Organic tendrils of light intensely spark and reach outwards from the core, reacting to an unseen focal point. The central sphere contains a glowing, minimalist letter 'W' or client logo that subtly pulses. The animation should show the tendrils dynamically flowing and shifting, creating a sense of interactive energy, then slowly contracting, and finally, subtly expanding again. Emphasize smooth motion, luminous glow, and a high-fidelity render suitable for cinematic web backgrounds."
    *   **Specifications:**
        *   **Duration:** 8-12 seconds.
        *   **Frame Rate:** 30 frames per second (fps).
        *   **Resolution:** Minimum 1920x1080 (ideally 4K if budget allows for file size/load time).
        *   **Content Progression:** The clip should be designed to visually represent an "interaction" cycle from start to finish, ensuring natural-looking keyframes for scrubbing.

2.  **ffmpeg Frame Extraction:**
    *   **Process:** Convert the AI-generated MP4/WebM video into a sequence of individual JPG or PNG frames. JPG is generally preferred for smaller file sizes.
    *   **Command:** `ffmpeg -i your_ai_clip.mp4 -vf "scale=1920:-1,fps=30" frame_%04d.jpg`
        *   `scale=1920:-1`: Resizes to 1920px width, maintaining aspect ratio. Adjust if targeting higher resolution.
        *   `fps=30`: Ensures 30 frames per second.
        *   `frame_%04d.jpg`: Outputs frames like `frame_0001.jpg`, `frame_0002.jpg`.
    *   **Total Frames:** An 8-second clip at 30fps will yield 240 frames. This provides excellent granularity for smooth scrubbing over a significant scroll distance.

3.  **Front-End Implementation (Preload & Scroll-Scrub):**
    *   **HTML Structure:**
        ```html
        <main>
            <section id="hero-animation-wrapper">
                <canvas id="hero-canvas"></canvas>
                <div class="hero-text-overlay">
                    <h1 class="fade-in-on-scroll">Client's Name / Product Title</h1>
                    <p class="fade-in-on-scroll">Catchy Tagline or Value Proposition</p>
                </div>
            </section>
            <section id="content-spacer"></section> <!-- For scroll height -->
            <section id="features-showcase">
                <!-- Static content sections -->
            </section>
            <!-- ... other sections ... -->
        </main>
        ```
    *   **CSS for Hero Pinning:**
        ```css
        #hero-animation-wrapper {
            position: sticky;
            top: 0;
            width: 100vw;
            height: 100vh;
            overflow: hidden; /* Ensure canvas doesn't overflow */
            display: flex;
            align-items: center;
            justify-content: center;
        }
        #hero-canvas {
            position: absolute;
            top: 0;
            left: 0;
            width: 100%;
            height: 100%;
            object-fit: cover; /* Cover the entire section */
        }
        .hero-text-overlay {
            position: relative; /* Or absolute, z-index to be above canvas */
            text-align: center;
            color: #FFFFFF;
            z-index: 10;
        }
        #content-spacer {
            height: 300vh; /* This creates the scrollable distance for the animation scrub */
            background: transparent; /* Or a matching background color */
        }
        ```
    *   **JavaScript (using GSAP ScrollTrigger for robustness):**
        1.  **Preload Images:** Use `Promise.all` to preload all `frame_XXXX.jpg` images into an array of `Image` objects.
        2.  **Canvas Drawing Function:** Create a function `drawImage(frameIndex)` that clears the canvas and draws the corresponding preloaded image.
        3.  **ScrollTrigger Setup (GSAP):**
            ```javascript
            gsap.registerPlugin(ScrollTrigger);

            const canvas = document.getElementById("hero-canvas");
            const context = canvas.getContext("2d");
            const frameCount = 240; // Total number of frames
            const images = []; // Array to store preloaded Image objects
            let currentFrame = 0;

            // Resize canvas to match viewport and draw initial frame
            function setCanvasSize() {
                canvas.width = window.innerWidth;
                canvas.height = window.innerHeight;
                drawImage(currentFrame);
            }
            window.addEventListener('resize', setCanvasSize);

            // Preload images (simplified, actual implementation needs error handling)
            for (let i = 0; i < frameCount; i++) {
                const img = new Image();
                img.src = `path/to/frames/frame_${String(i + 1).padStart(4, '0')}.jpg`;
                img.onload = () => {
                    images[i] = img;
                    if (i === 0) {
                        setCanvasSize(); // Draw first frame once loaded
                    }
                };
            }

            // ScrollTrigger for scrubbing
            ScrollTrigger.create({
                trigger: "#hero-animation-wrapper",
                start: "top top", // Starts when the hero wrapper hits the top of the viewport
                end: () => `+=${document.getElementById("content-spacer").offsetHeight}`, // Ends after scrolling through the spacer
                pin: true, // Pins the #hero-animation-wrapper
                scrub: 1, // Smooth scrubbing (1 second delay)
                onUpdate: self => {
                    // Map scroll progress to frame index
                    const newFrame = Math.round(self.progress * (frameCount - 1));
                    if (newFrame !== currentFrame && images[newFrame]) {
                        currentFrame = newFrame;
                        drawImage(currentFrame);
                    }
                    // Optionally animate text overlay opacity
                    gsap.to(".hero-text-overlay", { opacity: 1 - self.progress, duration: 0.1 });
                }
            });
            ```
        4.  **Smooth Scroll Library:** Integrate `Lenis` (or `Locomotive Scroll`) for a buttery smooth scrolling experience across the entire page, which significantly elevates the premium feel.

        *   **Primary Background:** `#0F0F0F` (Deep near-black for a true premium feel).
        *   **Hero Accents (from AI clip):** `#FF00FF` (Vibrant Pink), `#8A2BE2` (Electric Blue-Violet), `#66FFCC` (Subtle Aqua/Cyan for secondary sparks/glows).
        *   **Text:** `#FFFFFF` (Headings, primary), `#BBBBBB` (Body copy, secondary), `#666666` (Footer, tertiary).
        *   **UI Elements:** `rgba(255, 255, 255, 0.1)` for subtle borders/dividers.
    *   **Typography:**
        *   **Headings (`<h1>`, `<h2>`):** `Poppins` (Google Font). `font-weight: 700;` (Bold), `font-size: clamp(2.5rem, 6vw, 5rem);`.
        *   **Body Text (`<p>`):** `Inter` (Google Font). `font-weight: 400;`, `font-size: clamp(1rem, 1.8vw, 1.15rem);`, `line-height: 1.6;`.
        *   **Slogans/Taglines:** `Inter` or `Poppins`, `font-weight: 500;`, slightly larger than body text.
        *   **Overall:** Use a `font-family` stack that includes a system sans-serif fallback for robustness.
