# VS Code Sidebar Reference

King David uses VS Code as his IDE. He has asked for plain-English explanations of each panel.
Use these analogies when referencing VS Code features in future sessions.

## The Activity Bar Icons (left strip)

| Icon | Shortcut | Name | Plain English |
|------|----------|------|---------------|
| Files | Ctrl+Shift+E | Explorer | The filing cabinet · all your project files |
| Magnifying glass | Ctrl+Shift+F | Search | Find any word across all files |
| Branch | Ctrl+Shift+G | Source Control (Git) | Time machine · checkpoints for your code |
| Play+Bug | Ctrl+Shift+D | Run and Debug | Slow-motion replay · run code step by step |
| Puzzle | Ctrl+Shift+X | Extensions | App store for VS Code add-ons |
| Beaker | (varies) | Testing | Quality checker · runs automated pass/fail tests |
| Claude icon | · | Claude Code | The AI assistant panel |

## Key analogies used
- Source Control = time machine / snapshot history
- Debug = slow-motion replay for code
- Testing = automated quality checker (green tick / red cross)
