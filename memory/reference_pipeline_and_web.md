## The One Line
Problem → Skill → Tool → Output → Value → Money → Freedom

## Frontend vs Backend
- **Frontend** = everything the client sees (website, email, CSV, demo, proposal)
- **Backend** = everything doing the work (Claude, Python, Firecrawl, Playwright, APIs)
- Analogy: frontend = restaurant floor, backend = kitchen

## Hooks / Webhooks / Triggers / Scheduled
| Type | Fires From | Example |
|------|-----------|---------|
| Hook | Inside your machine | Auto-save after task |
| Webhook | Another app over internet | Fiverr order → scraper starts |
| Web trigger | Anyone hitting a URL | Calendly booking → welcome email |
| Scheduled | A clock | 8am → /exec morning briefing |

## B2B vs B2C
- **B2B** = King David → Irish tradesperson/SMB (you sell to businesses)
- **B2C** = Tradesperson → homeowner (your client sells to people)
- Your value: you make your B2B clients better at serving their B2C customers
- Pitch: "I help plumbers reach more homeowners", not "I build AI tools"

## The Full Pipeline
```
Client problem
  → Frontend (they see the gig/website/email)
  → Trigger (order placed / webhook / scheduled / manual)
  → Backend (Claude reads skill → calls tools → produces output)
  → Output (CSV / website / email / proposal)
  → Client result (leads / bookings / revenue)
  → Money
```

## Model Strategy (cost vs power)
- Haiku → cheap, fast, retrieval tasks
- Sonnet → most tasks, best value
- Opus → complex reasoning, architecture, high stakes

## Value-Based Pricing (worked example)
- Client wastes 2hrs/week × €50/hr = €400/month = €4,800/year
- Charge €300 once → client ROI in under 1 month
- Retainer €120/month → client saves €280/month net forever
