# The Content Engine (5-skill suite for any brand/business)

**King, 2026-06-26:** these are **separate skills**, not one mega-skill, and together they are the
important toolkit for **online content for ALL brands and businesses** (incl. monetisation when the
brand's goal is revenue). This is the master index; each stage has its own deep-dive memory.

> **A complete content-marketing department in a box, run by King + AI.** Sell the whole suite as a
> service to a brand, or any single stage a la carte. This is the productized money machine, and it
> serves the same money goal as everything else.

## The 5 stages (each its own `/command` skill)
| # | Stage | Skill | Does | Deep-dive |
|---|-------|-------|------|-----------|
| 1 | **STRATEGY** | `/tsv` (new) | Find the winning product + winning videos; decode **Title·Script·Video** to model (format-model, never literal-copy). "What do we make + why will it win?" | [[learning-digital-product-viral-sales-model]] |
| 2 | **PLAN** | `/storyboard` (new) | A1 script + character/style **sheets** + shot-by-shot **storyboard**. Lock it free before spending. | [[reference-visual-production-pipeline]] |
| 3 | **PRODUCE** | `/video` (**exists**) | Generate + assemble (Nano Banana/Gemini + Seedance/MiniMax + ElevenLabs VO + ffmpeg/Remotion/HyperFrames). | [[reference-hyperframes-video-method]] |
| 4 | **DISTRIBUTE** | `/seo` (new) | Accounts + keyword research + on-post SEO + analytics + timing + scheduling. Get it FOUND + posted + measured. | [[reference-social-seo-distribution]] |
| 5 | **MONETISE** | `/funnel` (new, when revenue is the goal) | The offer/store/funnel + conversion tracking; turn attention into cash. Per-brand the OFFER differs (digital product / "DM to order" / ad revenue / services). | offer half in [[learning-digital-product-viral-sales-model]] |

**Chain:** find winner -> plan A1 -> produce -> distribute+SEO -> monetise. Front (1-2) is free
planning; spend starts at 3; 4-5 turn it into money.

## Recommended build order (minimalist: manual -> processize -> productize)
Do NOT build 5 skills blind. **Run all 5 stages BY HAND on ONE real project first** (Mum / Aunty /
King's own toolkit), see what actually works, THEN bake the proven steps into the `/command`s. Same
"manual first" rule as the installed minimalist skills. This proves the engine before we automate it.
