# Each 3D world must be TRULY unique · reskinning the same engine is not enough

**What happened (2026-06-03, session 16):** I built VEYRA (jewellery) + FLUX (fintech) by reusing the proven `levi-pro-v2` engine and only swapping the palette, copy, and hero geometry. King immediately spotted it: *"that 3d design i see you copy, each website will have unique."* He's right, same camera path, same tunnel-fly-through motion, same station layout = a reskin, not its own world.

**Why:** King's locked rule for the premium 3D venture is **each brand gets its OWN world: colour/font/MOTION/3D IDEA.** "Motion" and "3D idea" are part of unique, not just colour + hero. The same fly-through repainted reads as a template, which is exactly what the whole premium positioning rejects. [[feedback-top-tier-design-standard]] [[feedback-palette-personal-only]]

**How to apply:**
- For every new 3D build, change the actual **3D concept + camera motion**, not just paint. Examples of distinct ideas: orbit slowly around a single rotating hero (jewellery) · build/assemble a data-grid as you scroll (fintech) · drift through a floating gallery (architecture) · a product spinning on a turntable with the camera pushing in (fashion). Different camera behaviour, different scene structure, different signature move per brand.
- The engine's PRIMITIVES (Three.js setup, HDR IBL, Lenis scroll, bloom, FPS guard, the hard-won lessons) are fine to reuse, that's the toolkit. The WORLD built with them must be new each time.
- **Readability is mandatory:** overlay text on a moving 3D background must stay high-contrast and legible, strong text contrast, a subtle dark plate/scrim behind copy, real text-shadow, and don't drop body text below ~0.85 opacity. King also flagged the copy was "a bit hard to read."

Tie-in: update `[[skill-3d-web-builder]]`, "reskin" is a speed shortcut for a quick variant, NOT the standard for a portfolio/client piece. Portfolio + client = unique world each time.
