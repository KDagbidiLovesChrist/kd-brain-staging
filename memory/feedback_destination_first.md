Before starting ANY task, always run this check, in this order:

1. **Destination first**, what is the goal? Where are we trying to get to? Don't start moving until the destination is clear.
2. **Check memory**, scan MEMORY.md and relevant memory files for context. What do we already know that applies here?
3. **Don't miss context**, even day-to-day stuff (projects, recent decisions, upcoming tasks) might be useful. Check it.
4. **Keep it simple**, don't overthink, don't overcomplicate. Use logic. The simplest solution that reaches the destination is the right one.

**Why:** King David's instruction, avoids wasted effort, avoids repeating work already done, avoids overengineering.

**How to apply:** At the start of every task, before reading files or writing code, state the destination in one sentence. Then check memory. Then act.
