# Disclose the data BEFORE consuming it

**King's exact words, 2026-08-09:** *"before you get the info let me know all the data you consume."*

## The rule
Before opening any personal data source, stop and list:
1. **What was already consumed this session** (be honest, including things read earlier).
2. **What would be consumed**, source by source, and **whose data it is**, naming third parties
   explicitly when their private messages are involved.
3. **What gets written to disk as a side effect.** Reading WhatsApp leaves screenshots in
   `browser_profiles\_shots\` and attachments in `_downloads\`. "Just reading" is not zero trace.
4. **What leaves the machine.** Usually nothing. Say so plainly, because it is the thing he is
   actually asking about.

Then wait. Do not begin the read while presenting the list.

## Why this matters (it is not ceremony)
When asked, King **narrowed** the scope. A broad offer covering Whitney's individual thread, a Gmail
search of Cleo's correspondence, and possibly a full WhatsApp inventory came back as two words:
**"logos gc"**. One group chat. Everything else stayed unread. Guessing would have read a named
person's private housing correspondence and family legal advice that he never wanted opened.

Third party data is the sharp edge. King consenting to his own data is not the same as consenting on
behalf of Whitney, Cleo, or anyone in a group. Name the person, name what is in it, let him decide
knowingly.

## How to apply
- Applies to WhatsApp, Gmail, Granola, Drive, Notion, any MCP touching a real person's messages.
- Does **not** apply to King's own brain files, public web search, or reading tool source code.
- Reading a tool's own header to describe accurately what it touches is allowed and encouraged. That
  is how the disclosure gets to be true rather than approximate.
- Sending anything to anyone remains a separate yes, asked separately. See
  [feedback_no_cold_outreach_king_tried.md](feedback_no_cold_outreach_king_tried.md) and the
  prep-only rule in `rules\tools-safety.md`.
