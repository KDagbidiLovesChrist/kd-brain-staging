## What was actually said and agreed

**Product/pitch, as King described it:** a universal AI personal assistant ("Logos"), a "brain OS"
connecting all a user's tools, running on a multi-agent system (one main agent delegating to
sub-agents), built on Anthropic's Claude as the foundation engine, on a constant loop, with a
proprietary mathematical equation as the core logic, kept secret. A compound memory system built
on user data, aimed at user satisfaction, roughly 3 months of King's own data used to build his
prototype. Front end: dashboard/GUI app, with a plan for other companies (11 Labs named as an
example) to integrate it. Currently local, moving to a private cloud server only King can access.
Long term: King's own data centre and own LLM, tied directly to his day job (DCEO, Amazon).

**Business model, as King described it:** a tiered model system, similar in shape to
Anthropic/OpenAI's own tiers, highest tier for businesses, priced by investment level. A consumer
tier idea floated: roughly 400 US dollars a month for full personal-assistant use. An investment
option: a stake in King's company depending on how much someone invests, with access to the
company database scaled by tier. Targeting businesses first (to collect data), consumers in
roughly 6 to 7 months. King said a company approached him the day before (2026-08-07, matches the
Moyo meeting's own account); he is negotiating mutual stakes rather than exclusivity. Emphasis on
data privacy and security, data sectioned off, never crossing between personal and business, or
between users.

**The actual ask made to Muskhan:** wants them as a case study, to build a personal and business
assistant for them. King will share API key access to a client-facing instance, never the master
prompt or the equation itself (the black box model, exactly as defined above; his reported meeting
words were "share his prompt/API key access but not his secrets," recorded here with this
clarification so no future reader can parse that as prompt-sharing authorization). Muskhan
responded with interest ("it's a good model"), asked few questions overall.

**Technical architecture claims already made to this client:** Muskhan already built their own
marketing LLM from Nate's course, runs an open-source model locally, avoids API costs, pays only
for MCP servers, uses AI via terminal, VS Code, and other tools. King's system: a system-prompted
agent on Claude, running a constant end loop, based on a secret mathematical equation involving a
Venn diagram and a SQL database, described as the foundational engine others' systems would be
built on top of. A memory system sits on top, built from gathered data specific to each user's
needs and life goals, a predictive model King described as "near perfect, not perfect." Multi-agent
consensus: one main engine delegates to sub-agents that manage the user's ecosystems. For clients,
King builds a new custom prompt but will not reveal its internal structure, clients build their
brand on top of it and just talk to it, a diagnostic agent handles the rest.

**Deployment, as described:** currently local on King's laptop, being pushed to a private cloud
only King can access, client systems would run off that server. End product: a GUI/app/software
with dashboards, users interact by talking to it, or manually via the app or dashboard. Vision:
two-way integration with other companies' tools (use Logos inside 11 Labs, or 11 Labs inside
Logos).

**Data privacy commitments made to this client:** each user gets their own database, personal and
business data sectioned off with guard systems so nothing crosses, the client's own backend data
will never be sourced or shown in the presentation, security stated as the most important company
policy.
