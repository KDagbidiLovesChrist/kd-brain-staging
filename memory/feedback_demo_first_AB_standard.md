# A + B for every strong-fit job (demo-first)

King set this as the standard on 2026-06-09: for **every strong-fit Upwork/freelance job**, do BOTH:
- **A = the drafted proposal** (King's voice, zero em-dashes, answers their questions, links the demo).
- **B = a TAILORED live demo built for THAT job**, a real working thing on its own Vercel URL, themed to the prospect's brand/world, not a generic link.

**Why:** the demo-first move is what makes King the obvious "yes". A proposal that says "here is YOUR thing already built" beats every "I can build X" competitor. Proven this session: Studio Flow (yoga), GHL engine (loan brokerage), CopyForge (AI content), OceanHire (recruitment site) all got tailored demos.

## How to apply
- Match the demo to the prospect's world. Pick the right base from [[knowledge-demo-library]], then re-theme/rebuild for them.
- Live AI tools: reuse the serverless pattern in [[reference-live-ai-demo-pattern]] (CopyForge = the latest, marketing-content generator).
- Static/architecture demos: a clean branded blueprint page or a real site (OceanHire) deployed to Vercel.
- QA every demo before sending (0 console errors, mobile + desktop, no em-dashes) per [[reference-live-ai-demo-pattern]].

## Hard lessons baked in this session
1. **WRONG-DEMO MISTAKE (King caught it):** never show a brand-specific demo to a different client. I pointed a yoga studio at the contractor "10-Position Domination" page. King: "that's not the correct demo." Fix = build tailored, and [[knowledge-demo-library]] now routes the right demo per job type.
2. **WATCHER AUTO-DRAFTS CAN FABRICATE:** the [[reference-upwork-mail-watcher]] Haiku drafts once wrote "I've spent months wiring up ClickUp, Airtable..." (King never has). **Auto-drafts are first-pass FLAGS only, Opus/King reviews + rewrites before anything is sent.** Never paste an AUTO draft.
3. **Links work in Upwork proposals**, the client can click or copy a pasted URL; portfolio/demo links are allowed (off-platform CONTACT info is what's banned). Attachments are an optional bonus, not required.
4. **Price in the proposal only when the post explicitly asks for it** (e.g. OceanHire "4. Fixed project price"); otherwise price goes in the bid field, never the text.
