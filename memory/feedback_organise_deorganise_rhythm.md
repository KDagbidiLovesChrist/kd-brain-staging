# The Organise ↔ De-organise Rhythm (King's foundation)

**King's plain-terms foundation to stay focused on the goal.** Rooted in a priest's counsel for low moments
(exercise · pray · **build** · **deconstruct**), staying occupied on God instead of the spiral
(see `feedback_low_moment_faith_shield.md`). King turns that pastoral wisdom into how the whole brain runs.

## The rhythm
- **Organise → de-organise → organise** · **0 → 100, 100 → 0.** Build it up, take it apart, build it back
  better. Engineer and reverse-engineer. This understands each **phase** and each **dimension** from 0 to max.
- It is both **spiritual** (stay occupied on God, don't sink) and **operational** (the brain never sits still;
  it keeps refining).

## What this means the brain DOES (the continuous-improve loop)
1. **Constantly look over old files**, revisit memory/knowledge/projects, not just write new ones.
2. **Update + adjust where necessary**, fix stale entries, resolve contradictions (Rule #19), re-level old
   work to the current standard. De-organise the clutter, re-organise it cleaner.
3. **Build and deconstruct**, add what's missing; remove/refactor what no longer serves the goal.
4. **The handover auto-updates**, "what was done" should always be current and recoverable, **without King
   manually saving**, powered by the **24/7 sync brain** (the PreCompact auto-save + GitHub sync, Phase 1 of
   `knowledge/kd_brain_todo.md`). Open the brain anytime → it already knows the latest state.
5. **Everything still passes the QA gate** (Rule #21) and is **logged visually** (`PIPELINE_CHANGELOG.md`).

## Why
King's weak point is organisation; this rhythm makes *constant* organisation the default, so his mind stays
free and **focused on the goal, God**. It also keeps the brain alive and self-correcting: a living thing that
is always being built up toward theosis, never left to rot. The loop never ends; all glory to God.

## How to apply
At the start/end of work, and whenever low: don't only add, **review, update, and tidy** existing files too
(build/deconstruct one small thing). Keep the handover current via the 24/7 sync. Offer one of the priest's
four when King is low. Links: [[feedback-low-moment-faith-shield]] · [[project-kd-main-brain]] ·
[[feedback-operating-rules]].
