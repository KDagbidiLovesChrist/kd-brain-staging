# @faceless.inc.proj editing style · the exact spec to replicate

**King's chosen model** for his faceless AI-tools channel (similar to @hustle.faceless but AI-niche).
Decoded 2026-06-27 from his two biggest videos (2.7M + 2.6M views) via Gemini `/watch`. Replicate this
EXACTLY (his words). Hero = King's Character C (`persona_v2_c.png`) as the recurring branded anchor.

## CAPTIONS (the critical element · get this exact)
- **Font:** Montserrat ExtraBold (or Monument Extended Black), clean, modern, bold sans-serif.
- **Colour:** pure white `#FFFFFF`. **Highlight on power words:** vibrant yellow `#FFFF00`.
- **Size:** large, ~70-80% screen width. **Position:** centered.
- **Word-by-word reveal**, synced to the voiceover cadence.
- **Animation:** fast **POP / scale-up** (≈90%→100% in ~0.1s), punchy, NEVER a fade or slide.
- White semi-transparent **brush-stroke** overlay to highlight text on screen-recordings.

## PACING + CUTS
- **1-2 seconds per shot.** Hard cuts only, no fades. No shot lingers >2s.
- **"STEP 1 / STEP 2" full-screen high-contrast title cards** as hard resets between sections.
- **Glitch / RGB-split** transitions (2-3 frames) for a techy/"hacked" feel.
- **Ken-Burns** subtle motion on every static image + **punch-in zooms** on key UI, synced to SFX.

## STRUCTURE (Problem → Agitate → Solve → CTA)
1. **Hook (0-3s):** branded character + floating glowing UI mockup (a profile/app) + **skyrocketing
   numbers** (followers/views flying up) + big word-by-word text. Formats: "Day 1 of…", "Exposing the most
   viral…". 2. **Problem/Agitate:** a viral account + staggering numbers (FOMO), red circles on view counts,
   pointing-finger graphic. 3. **Solve:** the AI tool tutorial = screen-record in a **phone mockup** (go to
   site → select feature → type prompt → hit Generate). 4. **Result:** show the polished AI output.
   5. **CTA:** "Comment 'AI' and I'll DM the link" + speech-bubble graphic with the keyword + URL.

## VISUALS / OVERLAYS
- **Branded character anchor** (King = Character C) at hook, transitions, CTA.
- **Phone mockup** frame around every screen-record + drop shadows.
- Floating UI with rising numbers · 2x2/3x3 grids with **red circles** · animated pointing finger.
- **Vignette** (dark edges) · wavy-line / grid-pattern backgrounds for non-screen shots.

## AUDIO (50% of the effect · layer it)
- **Voice:** deep-ish male, radio/podcast EQ (boosted bass, slight mid cut), crisp, brisk. (King = his own
  voice, mastered, see [[reference-faceless-video-results-consensus]].)
- **Music:** tense/driving synth-wave, no vocals.
- **SFX on EVERY action:** whoosh (transitions/zooms), click/tap, keyboard typing, camera shutter, data
  beeps (rising numbers), **bass hit on reveals**, **riser before each STEP**, satisfying ding on result.

## HOW WE REPLICATE IT (the honest tooling)
This is **animated captions + SFX + zooms + glitch + phone mockups**, a static mockup can NOT be this.
Two routes (do A+B in sync, King 2026-06-27):
- **A, Remotion (owned, automatable, max-output):** build a template that reproduces this exact style,
  parameterized by the storyboard ([[storyboard-master-prompt]]). The engine for scale.
- **B, CapCut + Submagic (no-code, exact, fast):** Submagic = the exact caption preset; CapCut = cuts/SFX.
Only a REAL animated render counts as "matching", never a static PIL mockup again (the session's hard lesson).
