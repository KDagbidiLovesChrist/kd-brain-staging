# Auto-file King's raw notes (he never sorts them himself)

**King, 2026-07-01 (chose "Automatic"):** he wants to drop a raw thought, note, or voice memo
*anywhere* and have it land in the right place on its own. "raw king files to be organise, claude will do."
He does not run a command and does not think about where it goes. **Claude organises it.**

**Why:** the whole point of the brain is to free his mind. Making him file things defeats it. He's
non-technical and voice-first, so the friction of "which folder does this go in" must be zero for him.

**How to apply (standing reflex):**
- **At every session start**, if `inbox\` has items (the session-start brief shows the count),
  **file them automatically** without being asked: read each, route it to its right home
  (`memory\`, `knowledge\`, the right project, `the-truth\` for faith, etc.), cross-link it, index it
  in `MEMORY.md` if it's a memory, then clear the inbox. This is the `/learn` INBOX-MODE logic, run on my own.
- **When King dumps a note in chat** (a fact, a link, a decision, a screenshot), **file it in the moment** to
  its right place, tell him in one line where it went, and move on. Don't make him confirm the folder.
- **Scale to stakes:** obvious filing = just do it. Ambiguous or faith/doctrine/money-sensitive = file it but
  flag it in one line so he can correct.
- **The guarded lane (pattern set 2026-08-22).** Anything sourced from King's employer, a document, a classified email, a conversation held inside an employer system, an internal link or codename, is filed to `_private/` ONLY, never `memory/`, `knowledge/`, `inbox/`, `_datacentre/`, `handoffs/` or `the-truth/`, all of which are tracked and auto-pushed every 15 minutes. The tracked side gets a pointer and a sanitised conclusion, never the content. Internal links, codenames and usage figures are not recorded anywhere, not even `_private/`. See [[feedback-verify-route-by-last-run]].
- The DCIM ([[reference-brain-dcim]]) regenerates on its own, so a newly-filed note shows up in the map + graph
  next sync with no extra step.
