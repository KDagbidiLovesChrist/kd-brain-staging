# The asymptote rule · C moves and E moves

**King asked for this to be written into the brain on 2026-08-10.** It extends Rule #17, which already
routes work by stakes. This routes work by **which variable is actually binding.**

## The rule

Because capability closes on its ceiling asymptotically, effort has diminishing returns, and there are
exactly two ways to gain:

- **A C move raises capability.** It shifts King **along** the curve toward the ceiling. Practice, hours,
  trying harder, better prompts, more polish. **Each later push buys less than the last.**
- **An E move changes the environment.** It **lifts the whole curve to a new ceiling.** Hardware, tools,
  money, a signed agreement, a lawyer, a better model, a different room, sleep.

**The operating rule: when effort stops producing gains, that is not a signal to try harder. It is the
signal that the ceiling is close and the next real gain is an E move.**

Grinding gets you nearer the ceiling. Changing your situation raises it.

## Why (the maths, per Rule #17's show-the-why standard)

The growth curve King wants is **asymptotic**, not exponential: it climbs steeply, then flattens toward
a horizontal line it never crosses. An exponential has no ceiling and therefore contradicts his own
08-09 law that X is a limit approached and never attained. On the correct curve the horizontal line
**is** the ceiling, and its existence is what creates diminishing returns. Raising C walks you along a
fixed curve. Changing E swaps the curve for a higher one.

**The ladder refinement (offered 2026-08-10, King has NOT yet accepted or rejected it):** each stage has
a real **finite** ceiling, so diminishing returns hold within a stage, while the **sequence** of ceilings
is unbounded. Locally finite, globally unbounded. This is how "infinite" can be true of the sequence
without ever being true of any single ceiling, which keeps the asymptote intact. Confirm with King
before relying on it.

## How to apply

At the start of any non-trivial task, alongside Rule #17's "trivial or non-trivial", ask:
**"is this a C move or an E move, and am I near the ceiling?"**

Proven live on 2026-08-10, all from that session's own measurements:

| Situation | The C move (low ceiling) | The E move (new ceiling) |
|---|---|---|
| 1TB declared against a 238GB disk | Nothing. The feasible set was empty. | Attach the 2TB drive. Done. |
| 24 GB free on C: | Delete harder | Move the Ollama store and transcripts off C: |
| Guarded work capped by an 8B local model | Better prompting against an 8B | Fit the strongest local model the RAM allows |
| Rights not protected | Build more product | **Sign the agreement. Get the lawyer.** |
| Anthropic keeping sessions 5 years | Be careful what you type | **Flip one toggle.** |

**The uncomfortable application, and King's own to make.** MONEY MODE (set 2026-07-02) was itself King
spotting a flat asymptote and calling it: "the brain is finished, every session defaults to the first
euro." Most work since has been brain-building, which is a C move against a ceiling he had already
identified as low. The E moves in front of him are outward-facing and cannot be delegated to any agent:
the unsigned agreement, the lawyer for the Amazon contract, and the client calls.
